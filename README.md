One sentence, at most 200 characters, in the voice of an alien tourist
giving planet Earth a one-star review while still slipping in a real
compliment about the food. This program writes that one sentence —
exactly 139 characters, no trailing newline — to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. Python 3.13, standard library only.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
cat output/entry.txt
```
